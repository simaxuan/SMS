### ② 未达标项与根因（评审反馈）
- **[高] P1-2 校验失效**：`ServerLauncher.cs` 原 `VerifyJarChecksumOptional()`（void）调用后紧跟无条件 `jarOk = true;`，覆盖校验失败写入的 `jarOk=false`，导致强校验形同虚设——篡改 jar 仍会被放行。
- **[低] P3-7 回滚文档缺失**：`.bak` 已生成但 README 未说明如何回滚。

### 迭代优化与修复
1. **P1-2**：将 `VerifyJarChecksumOptional()` 改为返回 `bool`——缺失 `.sha256`/哈希非法/一致/异常均返回 true（放行，保单机免配），不一致返回 false（阻断）；`CheckJar` 处改为 `if (!VerifyJarChecksumOptional()) { jarOk=false; Log失败; return; }` 后才 `jarOk=true`。强校验真正生效，且不破坏无 `.sha256` 的单机免配分发。
2. **P3-7**：`publish/README.txt` 补充 `.sha256` 强校验说明 + `.bak` 回滚操作（停服→备份→覆盖→重启）。
3. 重新编译启动器 exe（RC=0，csc 4.14.0），同步 `publish/ExamScoreServerLauncher.exe`（58368B）。
