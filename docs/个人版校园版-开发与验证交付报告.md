## 二、架构概览

```
统一 Spring Boot 进程（页面 + /api）
   │
   ├─ /api/auth/**      注册/登录/登出/当前用户（放行鉴权）
   ├─ 业务接口          由 AuthInterceptor 校验 X-Token（401）
   │      ├─ 老师（TEACHER）：学生/成绩/统计/字典（横截面）
   │      └─ 家长（PARENT）：绑定、孩子趋势、本人小测录入
   └─ 成绩来源隔离      Grade.source('teacher'|'parent') + creatorAccountId
```

- 鉴权：内存 token（UUID→accountId），`BCryptPasswordEncoder` 哈希密码，未引入完整 Spring Security。
- 角色：`Account.ROLE_TEACHER` / `ROLE_PARENT`；`LoginUserContext`(ThreadLocal) 保存当前账号。
- 绑定：`ParentStudentBind(parentAccountId, studentId)`，`unique(parent,student)`。

- `service/GradeService.java`：按角色分支；家长须绑定、仅可管理本人 parent 来源

- `controller/StudentController / DictionaryController / ExamController`：写操作校验老师角色
- `config/DataSeeder.java`：预置 1 老师（admin/admin123）+ 1 家长（parent1/parent123）+ 绑定 + 家长来源种子成绩

**权限矩阵（核心）**

| 操作 | 老师(TEACHER) | 家长(PARENT) |
|---|---|---|
| 查看学生列表 | ✅ 全校 | ❌ 403 |
| 录入成绩 | ✅ source=teacher | ✅ 仅绑定学生 source=parent |
| 修改/删除成绩 | ✅ 仅 teacher 源 | ✅ 仅本人 parent 源 + 绑定 |
| 修改对方来源成绩 | ❌ 403（不可改家长成绩） | ❌ 403（不可改老师成绩） |
| 班级统计(course) | ✅ 仅 teacher 源 | ❌ 403 |
| 孩子趋势(student-trend) | ✅ 任意学生 teacher 源 | ✅ 仅绑定学生（teacher 只读 + 本人 parent） |
