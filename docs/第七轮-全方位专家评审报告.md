## 1. 架构与多租户设计（88/100）

### 达成项 ✓
- 单库内 `school → level → class → student` 四级归属，方案 A「source 表显式 school_id、推导表 join 校验」落地正确，`Grade` 无冗余 school/classId 靠 join Student 推导，符合既有原则。
- 多租户闭环完整：`/api/schools`、`/api/levels`、`/api/teacher-classes` 三组 CRUD + 三级数据范围（class/level/school）+ DataSeeder 三级种子 + school_id 写入链（school/level/teacher_class/class）全通。
- 标准分三模式（equal/full-weighted/custom-weighted）与多科总分四口径（totalScore/totalFull/totalPercent/stdScore）真实接入统计计算层。

### 待改进 ▲
- **A4/前端已就绪但权限边界未全链**：`GradeService` 老师写操作未做班级归属校验、`comparison` 未按老师 DataScope 过滤（依赖 teacher_class 基建，已列为 backlog）。
- teacher-classes assign 接口当前无「老师-班级跨校一致性」强校验（需在服务层断言 school_id 一致）。

### 风险 ★

## 4. 安全（82/100）

### 达成项 ✓
- 身份证 AES 加密 + `id_card_hash` BCrypt 脱敏（@JsonIgnore / WRITE_ONLY），绑定四要素（学号+姓名+手机号+身份证后8位）+ 密码强校验。
- 失败锁定 5 次/15 分钟（423）、手机号唯一登录、家长越权写入守卫（ensureBound/ensureManageable）。
- 多租户跨校拒绝：school_id 取登录上下文不信任请求体。

### 待改进 ▲
- **内存 token 会话化**（重启失效、无过期/集中失效）——历史遗留，v5 认可单机可接受。
- **localStorage 存 token 的 XSS 面**（httpOnly+CSP 未上）——C 类生产化清单。
- BCrypt 密码哈希无盐字段区分（内部可接受）。

### 风险 ★
- **XSS（localStorage）与内存会话**为生产级必改项，单机演示不阻塞。
