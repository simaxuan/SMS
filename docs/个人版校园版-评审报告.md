### 确认安全（评审肯定，无需改动）
- 来源隔离闭环：老师 list/search/courseStats 恒 `source='teacher'`；家长 list/trend/visibleGrades 限定绑定+teacher+本人 parent，无跨绑定/跨来源泄露。
- 全量 `@Query` 为命名参数 JPQL，无 SQL 注入。
- `LoginUserContext` ThreadLocal 由 `afterCompletion` 清理，无陈旧泄漏。
- 家长端交互正确：学号+姓名精确绑定、解绑二次确认、趋势只读+家长录入标注、小测录入仅本人 parent 可编辑。
- Student/Exam/Dictionary/Parent/Statistics 控制器角色校验逐端点核对正确。

### 遗留建议（未在演示版实施，生产前处理）
| 级别 | 建议 | 说明 |
|---|---|---|
| P1 | 会话加 TTL / 外置（Redis/JWT） | 当前内存 token 重启失效、永不过期 |
| P1 | 生产关闭 `spring.h2.console` 与内存库 | 演示保留；生产用 `application-pg.yml`，console 必须关 |
| P2 | 解绑学生后的家长成绩处理策略 | 解绑后 parent 成绩不可见但仍残留；需产品明确 |
| P2 | DB 级外键（@ManyToOne） | 现为 Long 裸 FK，引用完整性靠应用层 |
| P2 | `findByStudentIdIn` 无 source 下沉 | 现由服务层内存过滤保证，建议下沉 SQL |
| P2 | avg 绝对分口径 + 聚合索引 | 满分不一致时均值歧义；建议补 `(exam,course,source)` 索引 |
| P2 | token 存 localStorage XSS 风险 | 生产建议 httpOnly Cookie + CSP |
| P2 | DataSeeder 无事务 / 跳闸开关脆弱 | 建议 `@Transactional` + 更稳的播种标记 |
