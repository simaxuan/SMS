## 三、后端改动清单

### 新增
- `entity/SystemSetting.java`：键值对设置实体；`@Table(name="system_setting", uniqueConstraints=@UniqueConstraint(columnNames="skey"))`；字段 `id/key/svalue/remark/createdAt`（**`value` 为 H2 保留字，列名用 `svalue`**）。
- `repository/SystemSettingRepository.java`：`findByKey`、`findAllByOrderByIdAsc`。
- `service/SettingsService.java`：`KEY_PARENT_RANK_VISIBLE="parent_rank_visible"`；`getBool` / `listSettings()`（**恒返回 boolean**）/ `update(key,value)`（仅允许该 key，老师可改）。
- `controller/SettingsController.java`：`GET /api/settings`（登录可读）、`PUT /api/settings/{key}`（仅 TEACHER）。
- `src/test/java/com/exam/SettingsAndAnalysisTest.java`：6 个集成测试（排名开关读写/家长 403/排名接口/班级对比/自定义小测/绑定关系落库）。

### 修改
- `entity/Exam.java`：新增 `source='school'`（默认）、`creatorAccountId` 字段。
- `repository/ExamRepository.java`：`findAllBySourceOrderByIdAsc`、`findBySourceAndCreatorAccountIdAndName`、`findAllBySourceAndCreatorAccountId`。
- `service/ExamService.java`：`list()` 只返回 school 源；新增 `listCustom(parentAccountId)`、`findOrCreateCustom(parentAccountId,name)`（按 source+custom+creator+name 查或建）。
- `controller/ExamController.java`：`GET/POST /api/exams/custom`（仅 PARENT）。
- `dto/BindRequest.java`：新增 `@Size(max=16) String relation`。
- `service/ParentService.java`：`bind()` 写 `b.setRelation(...)` 并回写 relation。
- `repository/GradeRepository.java`：新增 `rankRows(examId,courseId,source)`、`courseRowsByExam(courseId,source)`（修正重复 select 列 g.examId）。
- `service/StatisticsService.java`：注入 `ClassRepository`+`SettingsService`；`comparison(examId,courseId)` 真实聚类对比（TreeMap 按 studentId→classId 分组聚合）+ `overall`；新增 `ranking(examId,courseId)`（改用 `List<Map>` 避免 Jackson 序列化失败、含并列名次、家长受开关控制返回 mine/disabled）；新增 `progress(courseId,limit,regress)`（相邻考试得分率 delta，进步/退步）。
- `controller/StatisticsController.java`：`comparison` 改 `(examId,courseId)`；新增 `GET /api/statistics/rank`、`GET /api/statistics/progress`。
- `config/DataSeeder.java`：注入 SystemSettingRepository，种子 `parent_rank_visible=true`（备注"家长端是否展示孩子排名"）。

## 四、前端改动清单

### 新增
- `views/Exam.vue`：考试管理页（列表 + 新增/编辑/删除，老师角色）。
- `views/Settings.vue`：系统设置页（排名开关 `el-switch` 调 settingsApi，老师角色）。

### 修改
- `api/index.js`：`examApi` 加 `customList/customCreate`；`statApi` 加 `rank/progress`；新增 `settingsApi(list/update)`。
- `router/index.js`：加 `/exams`、`/settings` 路由（TEACHER）。
- `App.vue`：菜单加"考试管理""系统设置"（图标 Notebook/Setting 全局注册）。
- `views/Dashboard.vue`：`onMounted` 并行拉 `dictApi.classes()/courses()` 填真实班级数/课程数（修复原 `'-'` 硬编码）。
- `views/GradeEntry.vue`：批量提交去掉 `?? 60`（未填分数跳过并提示）；新增单条"修改"对话框（openEdit/saveEdit 调 gradeApi.update）；load() 按 examId/courseId/studentId 筛选（修复原拉全量）。**修复 `:label-width="60px"` 语法错误 → `label-width="60px"`**。
- `views/Statistics.vue`：**重写为多 Tab**——单科统计 / 班级对比（statApi.comparison + 柱状图）/ 成绩排名（statApi.rank）/ 进步退步（statApi.progress）/ 成绩预警（复用 rank 数据过滤 percent<60）。
- `views/parent/ParentBind.vue`：绑定表单加"关系"下拉（父亲/母亲/爷爷/奶奶/外公/外婆/其他），提交带 relation。
- `views/parent/ParentEntry.vue`：**重写为自定义小测解耦**——"小测名称"独立输入框（examApi.customCreate 建/复用 custom 考试），不再套用校内考试下拉；列表 examName 映射 custom 名。
- `views/parent/ParentTrend.vue`：新增"最新考试排名"卡片，调 settingsApi.list() 判断开关 + statApi.rank() 拉绑定孩子名次（开关关则显示警告并隐藏）。
- `views/GradeQuery.vue`：加"导出 CSV"（BOM+Blob，Excel 不乱码）与"打印"（window.print() + @media print 包裹 #print-area）。

## 六、本次落地中发现并修复的问题

| 问题 | 根因 | 修复 |
|---|---|---|
| SettingsAndAnalysisTest 编译失败（找不到 body） | `body(MvcResult)` 被 4 处调用但类中从未定义 | 补 UTF-8 解码的 `body()` 类级方法 |
| Vue 构建 `Identifier directly after number` | `:label-width="60px"` 冒号绑定把 px 当表达式 | 改为 `label-width="60px"` |
| SystemSetting 建表失败 | H2 保留字 `value` | 列名改 `svalue` |
| 家长绑定测试 400 乱码 | getContentAsString() 默认 ISO-8859-1 | 测试改用 getContentAsByteArray()+UTF-8 |
