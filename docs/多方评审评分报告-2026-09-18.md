## 三、分维度明细与依据

### 1. 技术方案合理性 —— 8.0 / 10
- **合理点**：JWT + HttpOnly/SameSite=Lax Cookie 会话、token 版本 + jti 黑名单集中失效，方案简洁且具备主动登出/改密失效能力；AES-GCM（随机 IV）替代 ECB 属正确升级；BCrypt 存密码；CSP/CSRF Origin 世界级纵深；单 jar 打包 + `-Dfrontend.bundle.skip` 可分离构建，`application.yml`(H2) + `application-prod.yml`(PG + `ProductionGuard` fail-fast) 双 profile 区分开发/生产。
- **短板**：会话失效态（jti 黑名单、登录失败计数、failCounter）为进程内内存，单节点重启即失效、无法水平扩展（多实例共享需外置存储）。

### 2. 代码实现质量 —— 8.5 / 10
- **证据**：Controller 仅透传、业务在 Service；多租户 `DataScopeService` 数据范围、`GradeService` 班域写校验、`StatisticsService` 三口径（totalScore / totalPercent / stdScore）实现完整；关键逻辑中文注释充分。
- **扣分点**：`JwtUtil` 以字符串 indexOf 手工解析 payload（非 JSON 库，脆弱）；`ALLOWED_ORIGINS` 硬编码 `localhost:5173`；少量魔法值（如 `ttl=480` 分钟）散落，`PASS_RATE_LINE=0.60` 已常量化。

### 3. 架构设计 —— 8.0 / 10
- **证据**：分层清晰、依赖无环；多租户以 school_id 逻辑隔离，Grade 不冗余 schoolId 统一由 `DataScopeService` 经 Student join 推导过滤，单一数据源一致性好（DataScopeService.java:24-25, 39-102）；跨校 teacher-class 绑定已有一致性断言。
- **风险**：租户隔离完全依赖「业务代码主动调用 DataScopeService」的纪律，数据库/查询层无物理外键与行级约束兜底，新增读路径漏调即越权（历史 P1 即此类问题）。

### 4. 功能完整性与可靠性 —— 8.5 / 10
- **证据**：核心闭环完整——登录/四要素绑定（默认密码=身份证后 8 位 BCrypt）、成绩增删改查（含批量，并发经 TOCTOU catch `DataIntegrityViolationException`→409）、多维度统计/对比/排名/趋势、家长排名隐私三档（aggregate/limited/full）、多租户隔离落地；`@Transactional` 测试可回滚。
- **亮点**：并发写冲突处理（409）、家长排名隐私档位、越权防护均有对应测试覆盖（ParentRankPrivacyTest、AuthFlowTest 等）。

### 5. 性能与安全性 —— 8.0 / 10
- **证据**：JWT verify 用 `MessageDigest.isEqual` 防时序攻击；AES-GCM 随机 IV，演示密钥 fail-fast 拒生产启动；`SecurityHeadersFilter` 全局 CSP/X-Frame-Options；`AuthInterceptor` CSRF Origin 校验；`ProductionGuard` 三道 prod 门禁；`StatisticsService` 批量 `findAllById` 消除 N+1。
- **风险**：jti 黑名单 / failCounter 内存化（单节点、重启失效、无法多实例）；JwtUtil 自研字符串解析非标准；ALLOWED_ORIGINS 写死不利部署。

### 6. 可维护性与可扩展性 —— 7.5 / 10
- **优点**：命名清晰、中文注释充分（统计口径固化于文档）、扩展点合理（`SettingsService` 驱动标准分三模式、`DataScopeService` 可复用）。
- **短板**：
  1. `StatisticsService` 为 931 行“上帝类”（注入 10+ Repository、14 方法），排名/对比/进步/趋势耦合，违反单一职责。
  2. 成绩来源常量 `"teacher"` / `"parent"` 字符串字面量散落多处（Stat:92/171/879 等），无枚举，易拼写漂移。
  3. 前端引入 Pinia 却无任何 store 文件（死依赖）。
  4. 默认 profile 仍 H2 + create-drop + seed 开启，靠 guard 兜生产。

### 7. 文档与测试覆盖度 —— 7.5 / 10
- **实测**：后端 9 个测试文件共 **62** 个 `@Test`（AuthFlow 10、GradeService 16、SettingsAndAnalysis 12、ParentRankPrivacy 7、SchoolLevelMultiTenant 5、ReadScopeGuard 4、StatisticsMetric 5、EncryptBind 2、LoginLock 1）；前端 2 文件 **12** 个用例（useAuth 6、routerGuard 6）——与既有声明一致。
- **不足**：前端仅 12 例偏薄，组件渲染/API 集成/ECharts 用例缺失；文档数量多但历史快照散落，部分需求规格（如 FR-103/FR-105）口径仍过期，未同步最新三口径统计。

## 四、主要优点（汇总）

1. **安全纵深完善**：JWT+Cookie、AES-GCM、BCrypt、CSP/CSRF、SecurityHeadersFilter、ProductionGuard 生产门禁齐备，且已用 `MessageDigest.isEqual`、随机 IV 等消除常见弱点。
2. **多租户设计一致**：统一由 DataScopeService 单一数据源推导数据范围，教师/家长可见性、越权防护均有明确实现与测试。
3. **业务闭环完整**：成绩录入→统计→对比/排名/趋势→报表→家长隐私档位，并含并发 409、越班拒绝等边界处理。
4. **测试证据扎实**：后端 62 例覆盖认证、成绩、设置、隐私、多租户、数据范围、统计、加密、锁定等关键路径，且都经编译/运行验证。

## 五、风险与不足（按优先级排序）

| 优先级 | 风险/不足 | 影响 | 建议方向 |
|:---:|------|------|------|
| P1 | 会话态（jti 黑名单/失败计数）进程内存化 | 重启失效、无法多实例/水平扩展 | 迁 Redis，JWT 失效态共享 |
| P1 | 租户隔离为约定式，查询层无强制兜底 | 新增读路径漏调 DataScope 即越权 | Grade 冗余 school_id+索引，统一 Repository 行级过滤或补 DB 外键 |
| P2 | `StatisticsService` 931 行上帝类 | 难维护、难测试 | 拆分为 Ranking/Comparison/TrendService + 公共 StatMath |
| P2 | 来源/角色字符串常量无枚举 | 拼写漂移、扩展易错 | 引入 SourceType 等枚举常量 |
| P2 | 前端测试仅 12 例且无组件/API 用例 | 前端回归保障弱 | 补组件渲染、API 集成、ECharts 快照用例 |

| P3 | 文档快照散落、部分口径过期、Pinia 死依赖 | 文档与代码漂移 | 统一版本归位、同步三口径、清理死依赖 |

## 六、针对性改进建议（落地排序）

1. **外置会话与失效态（ROI 最高）**：将 jti 黑名单、登录失败计数迁至 Redis，支持多实例与重启持久；JWT 密钥 / ALLOWED_ORIGINS / 锁定阈值全部外置配置。
2. **租户隔离下沉**：Grade 冗余 `school_id` 并加索引，统一 Repository 行级过滤（或补 DB 外键），使「漏调 DataScope 即越权」从约定式升级为强制式。
3. **拆分上帝类**：`StatisticsService` 按职责拆为 Ranking / Comparison / Trend + 公共统计工具，消除 931 行单类。
4. **常量枚举化**：引入 SourceType（TEACHER/PARENT）、角色、school 维度枚举，替换散落字符串字面量。
5. **补齐前端测试**：新增至少组件渲染 + API 集成 + ECharts 用例，达到与后端相当的回归保障。
6. **文档刷新与清理**：同步 FR-103/FR-105 等过期口径至三指标统计现状；清理历史快照与 Pinia 死依赖，保持「文档=代码」一致。

## 七、结论

项目已达到**可上线标准**：安全纵深完善、多租户与业务闭环落地、后端测试证据扎实，综合评分 **8.0/10（良好 B+）**。

后续迭代替换的**最高优先级**是把「约定式」的会话态与租户隔离升级为**强制式/可扩展**（Redis 外置 + 查询层兜底），同时消除 `StatisticsService` 上帝类与前端测试偏薄两个结构性短板。按上表 P1→P2 顺序逐项落地，即可将综合评分稳定推升至 8.5+。
