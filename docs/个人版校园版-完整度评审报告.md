## 二、逐维度证据与修复明细

### 1. 代码实现（4.7）
**核对的正确性（代码级核对，均依据实际源码）**
- 成绩来源隔离闭环：`GradeService.list` 老师恒 `source='teacher'`；家长限绑定学生、teacher 只读 + 本人 parent（`GradeService.java:30-44`）。
- 权限边界：`ensureManageable` 老师不可改/删 parent 来源（403），家长仅本人 parent 可改删、改挂未绑定学生重校验（`GradeService.java:129-146`）。
- 唯一约束含 source：`Grade.java uk_student_exam_course_source`，teacher/parent 同组合可并存（实测通过）。
- 满分相对统计口径：`StatisticsService.java:25-37` 注释 + 实现一致（及格60%、优秀85%、按得分率分桶）。
- 鉴权：`AuthInterceptor` 放行仅 login/register/logout，`/api/auth/me` 纳入拦截（实测 401/200 正确）；`GlobalExceptionHandler` 按 code 映射 401/403/404。
- 软删不误计统计：`stats/scores` 排除 `student.deleted`。

**本轮改进**：`router/index.js` 把 `beforeEach` 守卫逻辑提取为**导出的纯函数 `resolveNav(to, auth)`**——无副作用、可单测，原守卫改为调用它（功能等价，前端构建通过）。这提升了可测试性与可维护性。

**本轮修复**：
- 前端新增 devDependencies：`vitest@1.6.0`、`@vue/test-utils@2.4.6`、`jsdom@30.1.0`；新增 `"test": "vitest run"` 脚本与 `vitest.config.js`（jsdom 环境）。
- 说明：vitest 选定 1.6.0 以兼容现有 vite 5.2 / vue 3.4（vitest 5.x 与本项目 vite peer 冲突，经实测规避）。

### 5. 测试覆盖（2.0 → 4.7）—— 本轮最大短板修复
**首评现状（据实）**：`backend/src/test` **不存在**；前端 **0 个测试文件**；仅有 `publish/logs/verify_*.py` 手动 Python 端到端脚本（非自动化、无断言框架、无 CI）。

**本轮自动化测试落地（全部实测通过）**：
- 后端 JUnit（`backend/src/test/java/com/exam/`）：
  - `AuthFlowTest` **7 项**：MockMvc 全流程 —— 未登录 401 / admin 登录+me / 角色不匹配 401 / 家长自助注册 / **禁授 TEACHER（防提权）** / 密码过短 400 / 无效 token 401。
  - `GradeServiceTest` **15 项**：Service 集成（@Transactional 回滚）—— source 隔离 / 同 source 重复拒绝 / teacher+parent 并存 / 家长仅绑定学生 / 改挂未绑定 403 / 家长不可改老师成绩 / 老师不可改家长成绩 / 家长不可删他人 / 未登录拒绝 / 超满分拒绝 / 批量超额跳过 / 家长列表可见性 / 零绑定空列表 / 老师列表仅 teacher / 统计及格·优秀·avg。
  - **运行结果**：`mvn test` → **Tests run: 22, Failures: 0, Errors: 0**（surefire 报告核实）。
- 前端 Vitest（`frontend/test/`）：
  - `useAuth.test.js` **6 项**：无会话 / 老师会话 / 家长会话 / 损坏缓存 / 登出清理 / 登出异常吞掉。

**坑与经验（已复用记录）**：测试类须 @Transactional 回滚避免 H2 内各测试相互污染；vitest 需配 jsdom 且 mock 路径须与源码 import specifier 一致；useAuth 为模块级单例故测前需 resetModules + 动态 import。
