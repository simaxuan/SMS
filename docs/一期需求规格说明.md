# 考试成绩管理系统 —— 一期需求规格说明

- 版本：v1.0
- 状态：已评审
- 适用范围：一期交付范围

## 1. 背景与目标

为便于教师/教学管理者统一管理学生基础信息与考试成绩，建设一个**考试成绩管理系统**。一期聚焦四大核心模块：学生信息管理、成绩录入、成绩查询、成绩统计，并为每个模块提供完整的增删改查能力，形成"基础数据 → 成绩录入 → 成绩查询 → 成绩统计"的完整数据链路。

## 2. 用户角色

| 角色 | 说明 |
| ---- | ---- |
| 管理员 | 学生/班级/课程基础数据维护，成绩批量管理 |
| 教师 | 成绩录入、成绩查询 |
| 查看者 | 仅查看成绩统计与明细（可选，一期不强制权限区分） |

一期不引入复杂 RBAC 权限体系，系统为单角色可操作模型，重点是功能性交付。

## 3. 模块与用例

### 3.1 学生信息管理（Student）

| 编号 | 用例 | 说明 |
| ---- | ---- | ---- |
| UC-101 | 新增学生 | 录入学号、姓名、性别、班级、出生日期、联系电话等 |
| UC-102 | 修改学生 | 编辑学生信息 |
| UC-103 | 删除学生 | 逻辑删除（软删除），历史成绩保留 |
| UC-104 | 分页查询学生 | 列表分页展示 |
| UC-105 | 搜索学生 | 支持学号/姓名/班级关键词模糊搜索 |
| UC-106 | 详情查看 | 查看学生完整信息 |

### 3.2 基础数据（班级 / 课程）（Dictionary）

| 编号 | 用例 | 说明 |
| ---- | ---- | ---- |
| UC-201 | 班级管理 | 班级增删改查 |
| UC-202 | 课程管理 | 课程增删改查 |

### 3.3 成绩录入（Grade Entry）

| 编号 | 用例 | 说明 |
| ---- | ---- | ---- |
| UC-301 | 单条录入成绩 | 选择考试+课程+学生，填写分数 |
| UC-302 | 批量录入成绩 | 一次为多个学生录入同一考试+课程成绩 |
| UC-303 | 修改成绩 | 修改已录入成绩 |
| UC-304 | 删除成绩 | 删除某条成绩记录 |
| UC-305 | 唯一性校验 | 同一学生同一考试同一课程不得重复录入 |
| UC-306 | 分值域校验 | 分数须在 0-100 之间 |

### 3.4 成绩查询（Grade Query）

| 编号 | 用例 | 说明 |
| ---- | ---- | ---- |
| UC-401 | 条件查询 | 按考试、课程、学生等多条件组合筛选 |
| UC-402 | 查询明细 | 展示班级/学号/姓名/分数等明细 |

### 3.5 成绩统计（Grade Statistics）

| 编号 | 用例 | 说明 |
| ---- | ---- | ---- |
| UC-501 | 考试课程统计 | 平均分、最高分、最低分、及格率、优秀率 |
| UC-502 | 分数段分布 | 各分数段人数分布（图表） |
| UC-503 | 多维度对比 | 不同考试/课程/班级横向对比（图表） |

## 4. 功能需求（FR）

- FR-101：学生学号唯一，班级名唯一。
- FR-102：删除学生采用逻辑删除，查询默认过滤已删除记录。
- FR-103：成绩记录满足 (学生, 考试, 课程) 唯一约束。
- FR-104：成绩分数校验区间 0~100。
- FR-105：成绩统计口径：及格线 60，优秀线 85，分段按 0-59 / 60-69 / 70-79 / 80-89 / 90-100。
- FR-106：所有列表支持分页。
- FR-107：系统初始化自动写入演示种子数据（班级/课程/考试/学生/成绩）。

## 5. 数据模型（核心表）

| 表 | 核心字段 |
| ---- | ---- |
| class_entity | id, name(唯一), createdAt |
| course | id, name(唯一), createdAt |
| exam | id, name, examDate |
| student | id, studentNo(唯一), name, gender, classId, birthDate, phone, deleted(软删), createdAt |
| grade | id, studentId, examId, courseId, score, unique(studentId,examId,courseId) |

## 6. 非功能需求（NFR）

- 可用性：演示环境开箱即用（H2 内存库 + 种子数据）。
- 兼容性：支持主流现代浏览器（Chrome / Edge）。
- 响应性：前端采用响应式布局。
- 可维护性：前后端分离、模块化分支管理、统一异常处理与统一响应结构。
- 可扩展性：预留 PostgreSQL 生产 profile，便于切换真实数据库。

## 7. 验收标准

- 四大模块增删改查可用且经过接口级验证。
- 唯一性校验与分值域校验生效。
- 统计模块输出正确（平均/最高/最低/及格率/优秀率/分段分布），修复聚合类型转换问题。
- 前后端编译构建通过，后端可运行并自动初始化演示数据。
