## 二、各项改动影响评估（改前必查）

| 改动 | 影响面 | 连带风险 | 规避措施 |
|---|---|---|---|
| SettingsService full 守卫 | 仅写 full 档位老师被 403 | 若 admin 非 SCOPE_ALL 会被误拦 | 校验 `SCOPE_ALL` 或 role=admin 双放行 |
| ParentService.bind 捕获 | 仅重复绑定返回 409 | 其他异常仍原样抛 | 仅捕获 DataIntegrityViolationException |
| createTeacher @Transactional | 方法执行改为单事务，异常整体回滚 | 无（本应如此） | 依赖注入已就绪 |
| http.js redirect | 登录回跳逻辑 | 登录页需处理 query | 登录页读 `route.query.redirect` 回跳 |
| 启动器 .sha256 可选校验 | 存在 .sha256 才校验，缺失不阻断 | 无 | 需重编 exe |
| pg 库密必填 | 用 pg profile 必须配环境变量 | 未配则启动失败（fail-fast 属预期） | 文档标注必填项 |
| V2 占位符 | 仅迁移脚本注释/文档 | 无 | 不改 SQL 逻辑 |
| savePreference 捕获 | 仅重复首建 409 | 无 | 与 P1-4 一致 |

> **原则**：每项改动前先读相关支撑类与调用方（遵循二轮"防误报"习惯）；不重构既有算法；能不动就不动，只做针对性最小修改。
