## 三、优化1：排名个性化（家长配置）落地清单

**后端**
- 新增 `entity/ParentPreference.java`：`parentAccountId`(unique) + `classScope`(只看本班) + `showTies`(是否并列) + createdAt。
- 新增 `repository/ParentPreferenceRepository.java`：`findByParentAccountId` / `existsBy...`。
- `service/ParentService.java`：新增 `getPreference` / `savePreference`（默认 classScope=true, showTies=true）。
- `controller/ParentController.java`：`GET /api/parent/preference`、`PUT /api/parent/preference`（仅家长）。
- `service/StatisticsService.ranking(examId, courseId, classScope, showTies)`：
  - 老师：全校排名，`classScope` 忽略（恒全校），`showTies` 可配。
  - 家长：受「家长端排名开关」控制，再按偏好 `classScope`（仅孩子所在班级重算名次 + 返回该班全部学生）/ `showTies`（标准并列 1,2,2,4 或唯一顺延 1,2,3,4）。
  - 名次核心算法 `assignRank(sorted, ties)`：ties=true 标准并列；false 唯一顺延。
- `controller/StatisticsController.rank`：新增 `classScope` / `showTies` 可选参数。

**前端**
- `views/parent/ParentTrend.vue`：排名卡片上方新增「排名范围（只看本班/全校）」下拉 +「并列显示（显示并列/唯一顺延）」开关；`loadPref/savePref` 读写偏好并即时刷新排名；rank 请求带上 classScope/showTies。
- `api/index.js`：`parentApi.preference/savePreference`。

## 四、优化2：多学期维度落地清单

**后端**
- `entity/Exam.java`：新增 `semester` 字段 + 索引 `idx_exam_source_semester`。
- `dto/ExamRequest.java`：新增 `semester`。
- `service/ExamService.create/update`：写入 semester。
- `repository/ExamRepository.java`：`findBySourceAndSemester`、`@Query findDistinctSemesters`。
- `service/StatisticsService`：
  - `comparison(examId, courseId, semester)`：新增学期模式——该学期多场考试合并，每生取最新一次为代表按班级聚合（`semesterRows`）。
  - `progress(courseId, limit, regress, semester)`：新增 semester 过滤，仅在该学期内比较相邻两次考试。
  - 新增 `semesters()`：返回校内考试全部学期列表。
- `controller/StatisticsController`：comparison/progress 增 semester 参数；新增 `GET /api/statistics/semesters`。

**前端**
- `views/Exam.vue`：考试管理表新增「学期」列 + 表单学期下拉（filterable allow-create 可输入新学期）。
- `views/Statistics.vue`：
  - 班级对比 Tab：新增「范围」切换（按考试 / 按学期）+ 学期下拉。
  - 进步/退步 Tab：新增学期下拉（可空=全部学期）。
  - 加载 semesters 列表。
- `api/index.js`：`statApi.semesters`。
