# 个人版（家长端） vs 校园版（老师端）：成绩统计分析维度差异深度分析

> 文档性质：产品经理组建团队（产品 / 数据分析 / 前端可视化 / 后端）讨论产出的**统计维度差异基线**。
> 用途：作为两端差异化统计设计的输入；本报告不直接决定代码，供「开发后满足两端分析使用」对齐。
> 背景约束：家长录入成绩为「在家自学/小测」性质，**老师端不可见、不计入老师统计**（来源隔离 source=parent）。因此两端天然是两套不同的分析对象。
> **v5 同步**：统计口径升级为「三指标并存」——总分 `totalScore`、总得分率 `totalPercent`、标准分 `stdScore`（equal/full-weighted/custom-weighted，默认 equal，本期开放 custom）；多科总分经 `exam_course_group` 计算。

---

## 1. 结论：两端「统计对象」根本不同

| 维度 | 校园版（老师端） | 个人版（家长端） |
| ---- | ---------------- | ---------------- |
| 统计对象 | **群体**（班级 / 全校、某学科、某次考试） | **个体**（单个孩子的历次表现） |
| 数据范围 | 仅 `source=teacher` 录入的成绩 | 绑定孩子「老师成绩(只读) + 家长自录成绩」 |
| 核心问题 | 「这次考试这班/全校考得怎么样？」 | 「我的孩子最近在进步还是退步？哪科短板？」 |
| 视角 | 横向（同场考试班级/学科间比较） | 纵向（跨时间、跨学科比较个人） |

**一句话**：校园版分析**横向截面**（空间维度），个人版分析**纵向轨迹**（时间维度）。统计维度因此不应共用一套模板。

> **v5 三口径统一**：两端均基于同一「三指标」框架——`totalScore`（主展示，原始分累加）、`totalPercent`（总得分率，跨考试可比）、`stdScore`（标准分，跨科定位）。标准分支持 equal（默认）/full-weighted/custom-weighted 三种权重，本期开放 custom-weighted（科目权重可配置）。多科总分通过 `exam_course_group`（active 标记计入科目）计算。

---

## 2. 校园版（老师端）统计维度

### 2.1 关注指标（横截面）
- 总体：参考人数、平均分、最高/最低、**满分均分、得分率均值（满分相对）**
- **v5 三口径**：班级/全校 **总分 `totalScore`**（原始分累加，主展示）、**总得分率 `totalPercent`=Σscore/Σfull×100**、**标准分 `stdScore`**（各科得分率均值加权，equal/full-weighted/custom-weighted）；多科经 `exam_course_group` 计算
- 达标：及格率 / 优秀率（按满分×60%/×85%）、各班达标率对比
- 分布：得分率分数段分布（<60% … ≥90%）、是否呈正态/偏态
- 离散：标准差、差异系数（班级内部两极分化程度）

### 2.2 分析维度（切片）
| 切片 | 例子 |
| ---- | ---- |
| 学科 | 语文/数学/英语各科平均、及格率横向对比（雷达/柱状） |
| 班级 | 一班 vs 二班 vs 三班均分/及格率对比（柱状/分组柱） |
| 场次 | 期中 vs 期末均分变化（折线，班级口径） |
| 组合 | 某班某科某次考试分布堆叠柱 |

### 2.3 代表作图表
- 部门横向对比：分科/分班 **分组柱状图**（均分、及格率）
- 达标率：**漏斗/占比**（及格率、优秀率占比环形）
- 分布：**分数段直方图**（得分率分桶、叠加优秀/及格阈值线）
- 综合：班级均分 vs 及格率 **散点**（均值-达标双维度定位薄弱班）

## 3. 个人版（家长端）统计维度

### 3.1 关注指标（纵截面）
- **总分趋势**：历次考试总分折线（标注满分基准，看整体走向）
- **单科趋势**：各科得分率折线（消除不同满分影响，横向可比）
- **v5 三口径（个体）**：本人 **`totalScore`**（主展示）、**`totalPercent`**（总得分率，跨考试可比）、**`stdScore`**（标准分，跨科定位；权重可配 custom-weighted）；多科经 `exam_course_group` 计算
- **科内相对位置**（若允许家长看班内排名）：该生在班内的百分位（仅老师 source 数据），按 `parent_rank_detail` 仅返回本人+聚合
- **偏科识别**：各科得分率与自身均值/班平均差的雷达图 → 强弱科
- **稳定性**：总分/单科的标准差（波动大=不稳定）

### 3.2 分析维度（切片）
| 切片 | 例子 |
| ---- | ---- |
| 时间 | 历次考试（时间轴折线，纵轴主） |
| 学科 | 各科折线叠加 / 雷达 |
| 满分口径 | 统一用「得分率」消灭 100/120 满分差异 |
| 来源 | 老师成绩 vs 家长自录成绩可用**图例区分**（画风/颜色）但不相加进同一统计口径 |

### 3.3 代表作图表
- **总分趋势折线**（含满分线）
- **各科得分率多折线**（高亮最高/最低科）
- **学科雷达图**（强弱科一眼可见）
- 可选：班内百分位柱状（仅老师数据）

## 4. 两端统计维度的关键差异对照表

| 项 | 校园版 | 个人版 |
| ---- | ---- | ---- |
| 统计方向 | 横向截面 | 纵向轨迹 |
| 基本单位 | 群体（班/全校） | 单学生 |
| 主时间轴 | 次（可选） | **必须**（历次考试） |
| 主对比轴 | 学科/班级 | 学科/时间 |
| **统计口径（v5 三指标）** | `totalScore`/`totalPercent`/`stdScore` 并存，标准分权重 equal/full-weighted/custom-weighted | 同左；多科经 `exam_course_group` |
| 满分处理 | 按满分相对（得分率） | 按满分相对（得分率） |
| 排名 | 需要（班内/级部/校内三级范围名次） | 隐私档位 `parent_rank_detail`（默认 aggregate，仅本人+聚合） |
| 分数段分布 | 需要（直方图） | 不必须（个人分布意义小，可用得分率直观） |
| 及格/优秀率 | 群体口径 | 个人"是否达标"（单点 vs 满分线） |
| 来源隔离 | 只算 teacher | teacher(只读)+own parent(不混同) |
| 数据权限 | 全校/班级/级部（三级范围） | 仅绑定学生 |

**共用的底层能力**：满分相对统计（得分率/满分×60% 及格线）、ECharts、分数趋势折线——这部分已在本期「功能 ②④」先期落地，可作为两端统计通用组件复用。

## 5. 对后续开发的约束建议

1. **统计接口按角色分两套**：`/api/stats/teacher/*`（群体横截面）与 `/api/stats/parent/*`（个体轨迹），不强行合并为一个接口的复杂分支。
2. **统一三口径框架**：两端都以「`totalScore`/`totalPercent`/`stdScore`」三指标呈现，避免 100/120 满分混淆；标准分默认 `equal`，本期开放 `custom-weighted`（科目权重可配）；多科总分经 `exam_course_group` 计算，恒显满分基准。
3. **家长端数据范围**：仅返回绑定学生；老师 source 只读；家长 source 仅本人。
4. **排名需谨慎**：班内/级部/校内排名属敏感信息，家长端按 `parent_rank_detail`（默认 `aggregate`）仅返回本人名次 + 班级/级部聚合，**不返回全班明细**（或仅显示百分位），由产品配置。
5. **不混同统计**：家长自录成绩不并入老师统计；家长端展示时用来源标识（图例/徽标）区分「老师成绩」与「家长自测」。
6. **可扩展**：为未来「薄弱科建议、成绩波动提醒」预留字段（后续排期）。
